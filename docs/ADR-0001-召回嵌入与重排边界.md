# ADR-0001：召回嵌入与重排边界

- 状态：接受
- 日期：2026-08-06
- 适用版本：`1.0.0-rc.9`

## 背景

现有 `local-hash-v1` 是 32 维确定性特征哈希，只适合提供低权重 fuzzy 候选，不能作为真实
多语语义相似度证据。生产已配置的对话模型也没有自动获得 embedding 或 rerank 的数据授权。

## 决策

1. `local-hash-v1` 明确标记为 fuzzy hash，单独命中不得越过默认召回 `min_score`。
2. UUID、哈希、纯数字和随机长 token 禁用 fuzzy 通道；lexical/entity 精确匹配仍可返回。
3. 先使用版本化 query alias、通道分数、`min_score`、`min_margin` 和空结果语义降低误召回。
4. 本阶段不调用外部 embedding/rerank，不把对话模型复用为 embedding 模型，也不发送新的数据。
5. 后续候选必须同时具备：独立数据授权、版本化索引、旧/新双读金标、成本与延迟上限、索引
   回滚方案。未满足时保持本 ADR 的本地 fuzzy-only 决策。

## 后果

- 语义通道单独命中会返回 `no_match`，Hermes 不注入低置信结果。
- 精确 lexical、实体关系、时间和程序通道仍可独立过 Gate。
- 宽泛同义词能力先由可审计 alias 提供；新增 alias 必须带金标回归。
- 引入真实 embedding 属于新的架构和数据授权变更，不能随普通模型配置一并启用。
