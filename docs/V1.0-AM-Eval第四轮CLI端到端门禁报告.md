## 1. 覆盖范围

本 Gate 不再 monkeypatch 模型 adapter，而是从独立 CLI 子进程加载当前 Settings 和真实 LiteLLM，向
随机端口、仅绑定 `127.0.0.1` 的 OpenAI 兼容测试服务器发送两条合成样本。runner 随后通过真实
worker、PostgreSQL、policy、事实索引、recall、质量评分器和效率评分器完成闭环。

测试会自行：

1. 在隔离 PostgreSQL 中创建随机 `am_eval_cli_*` 数据库；
2. 执行当前 Alembic 全部迁移；
3. 冻结两条临时 manifest、SHA、turn allowlist 和 2 次模型调用预算；
4. 启动回环 OpenAI 兼容端点并执行 runner CLI；
5. 验证输出权限、任务终态、事实/引用和聚合指标；
6. 无论成功失败都关闭回环服务器并强制删除随机数据库。
