## 1. 本轮结论

隔离 atomic runner 的成功与超时路径均已通过真实 PostgreSQL、真实 worker 事务、真实事实存储与召回
链路验证。非生产外部模型 Key 尚未配置，因此本轮没有把公开合成样本发给模型供应商，也不把假模型
夹具分数当作真实质量分。

本轮 review 发现并修复三项会影响自动化可信度的问题：

1. 失败任务原先会打印 `FAILED` 但 CLI 仍返回 0；现在保留诊断输出后返回退出码 2；
2. 聚合结果原先固定声明 `external_data_sent=true`；现在按本地/外部端点和实际运行传递；
3. 24 次调用上限原先依赖 manifest/allowlist 间接约束；现在要求 `--max-model-calls` 精确等于冻结 case 数，
   不一致时在数据库写入前失败关闭。
