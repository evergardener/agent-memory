# Agent Memory for Hermes — V1.0 测试 Release 验收矩阵

## 1. 用途

本文将需求转为可验证的 release gate。每项必须有自动化测试、运行输出或恢复演练作为证据；“代码看起来支持”不算通过。

状态值：`未实现`、`实现中`、`已验证`、`阻塞`。测试 release 允许模型能力使用确定性测试替身，但真实 Hermes Provider、数据库、API、worker、安全边界和 UI 操作链路必须可运行。
