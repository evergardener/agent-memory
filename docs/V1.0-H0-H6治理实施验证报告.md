- 数据库治理集成：8 组场景全部 PASS：

  - H4 正向、负向和 resolved 召回金标达到计划门槛。
  - 历史 candidate 预过滤、模型四态校验、调用预算和报告正文隔离均为只读且失败关闭。
  - candidate apply 归并重复 evidence、保留 review、拒绝 canonical 漂移并支持 manifest 幂等重放。
