## 2. 数据库与自动化证据

- Alembic：空隔离数据库 `upgrade head` → `downgrade 0016_unified_memory` → `upgrade head`，最终
  `0018_preference_evidence (head)`。
- 单元/静态：Ruff PASS；`217 passed, 30 skipped`（集成项在隔离环境单独运行）。
- F2–F7 与治理集成：`30 passed`。
- 新增数据库治理集成：4 组场景全部 PASS：
  - current resolve 同步 item/fact/document，重复 resolve 不增加版本；
  - 偏好重复证据复用记录，相反/替代值只保留一个 active；
  - purge 遇到 preference evidence 等派生引用不再删除仍被使用的 evidence；
  - 模型重放和历史治理默认 dry-run，错误确认或 manifest 漂移失败关闭。
- 前端：6 个星图模型用例、TypeScript、Vite build 全部 PASS。
