## 4. 故障与恢复

| 场景 | 结果 |
| --- | --- |
| 核心 worker 停机 | API 接收证据，任务保持 `pending`；重启后 `done` |
| 过期租约 | `attempt_count 1 → 2`，任务完成 |
| API 停机 | Provider 空注入并继续回合；恢复后 `/health/ready=200` |
| 模型隔离 | `model_enabled=false`、无 key、无 model worker/job |
| 情节任务中断/重试 | 始终 1 个 episode、3 个步骤、4 个参与关系 |
| 上游更正 | 支撑 procedure 由 active 降为 dormant/candidate |
| 无效程序提炼 | 失败关闭，不影响事实、情节或普通召回 |
