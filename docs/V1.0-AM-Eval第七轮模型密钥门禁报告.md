## 1. 本轮目标与结论

真实外部模型 shakedown 的 runner 原本支持 `AGENT_MEMORY_MODEL_API_KEY_FILE`，但只读取文件，未验证
来源路径、文件类型、链接数量和权限，也允许直接环境变量覆盖。第七轮将安全文件注入改为强制 Gate，
并用假 key、loopback OpenAI 兼容端点和隔离 PostgreSQL 完成端到端验证。

结果证明当前 runner 可以在不泄漏 key 的前提下从受限文件执行模型链路；真实非生产 key 仍不存在，
24 条公开合成样本也尚未获得明确外发确认，因此没有启动真实模型运行。

## 2. 新增安全契约

评测 runner 现在强制要求：

1. `AGENT_MEMORY_MODEL_API_KEY` 必须为空；
2. `AGENT_MEMORY_MODEL_API_KEY_FILE` 必须指向仓库外非空普通文件；
3. 路径及任一父路径不能是符号链接；
4. 文件不能存在多个硬链接；
5. 直接父目录权限不得宽于 `0700`；
6. 文件权限不得宽于 `0600`；
7. 任一校验失败都发生在模型 profile 建立和数据库连接前。

通用模型运行仍保留原有配置兼容性；上述严格规则只作用于 AM-Eval 外部模型 runner。
