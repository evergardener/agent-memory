## 1. 本轮目标与结论

第二轮仍缺 M01/M02/M03/M07/M22/M23。它们不能由规则测试或过去面板计数倒推，但在开始真实数据
标注、外部模型调用或生产 shadow 之前，必须先冻结“什么算正确、分母是什么、哪些输入可公开”。

本轮完成了这层基础设施：原子事实金标具备 exact span、事实类型、生命周期、recallable、实体角色
和召回引用契约；两个评分器可生成六项 AM-Eval 指标的结构化测量。公开合成自检全部通过，但不会
写入 `round-2-agent-memory.json`，也不声明 Agent Memory 的实际质量提高。

## 2. 新增数据契约

`atomic-quality-selftest-v1` 包含 24 个合成场景：20 个生活/技术正向场景、4 个控制词/问句/附件
占位负向场景，共 24 条期望事实和 21 个引用问题，development/validation 各 12，blind 0。

每条正向事实必须固定：

- `statement` 与原始 evidence 的 Unicode 字符范围完全一致；
- `fact_type`、期望 `memory_state` 和 `recallable`；
- 稳定 `evidence_id` 以及 `evidence_index/span_start/span_end`；
- 实体名称、类型与现实角色；
- 可验证的 recall query 与期望 fact IDs。

数据加载器会拒绝错误 span、重复 claim/fact/query ID、未知引用、无原因空金标、SHA/计数不一致、
公开 blind 样本以及公开生产派生数据。私有/受限 manifest 可以承载真实脱敏 blind 金标，但文件不得
进入公开仓库。

## 3. 指标计算

### 3.1 事实与引用

`agent-memory-score-atomic-quality` 计算：

- M01：正确预测事实 / 全部预测事实；
- M02：命中的完整金标 claim / 全部金标 claim；
- M03：exact span 正确 / 已正确匹配的 claim；
- M07：召回事实正确且 recall/fact provenance 均含期望 source / 全部金标查询。

“文本一样但类型、生命周期或 recallable 错误”不算正确 claim。重复预测只命中一次，其余计为
false positive；零预测等无有效分母项保持未测。预测文件还必须绑定 dataset manifest SHA，同名但
内容已变化的数据集不能混用输出。

### 3.2 治理与模型失败

`agent-memory-score-efficiency` 只接受不含正文的聚合计数：

- M22 = `manual_review / (auto_admitted + manual_review)`；
- M23 = `terminal_failure / (terminal_success + terminal_failure)`。

M23 要求观察窗口内 unfinished model job 为 0；任一分母为 0 时对应指标保持未测，不把“没有流量”
报告成 0% 失败或 0% 人工治理。输入还必须固定 system revision、policy version、数据来源边界和
数据外发声明。隔离外部模型运行必须如实写为 `external_data_sent=true`；该聚合输入文件自身仍不得包含
任何记忆正文。

## 5. 安全 Review

- 真实金标与模型输出显式视为含记忆正文，不得提交公开仓库；
- 数据集路径仍限制在 manifest 目录内并固定 SHA；
- open manifest 禁止 blind 和生产派生数据，private/restricted 才允许；
- 评分器不调用模型、不连接数据库、不写生产；
- M22/M23 输入强制 `contains_memory_text=false`；
- review 后补充 manifest SHA、system revision 与 policy version 绑定，禁止错数据集和跨策略混算；
- 评分输出仅含聚合计数和指标，不回显事实、证据或召回正文；
- 当前变更不修改模型配置、Hermes profile、生产 namespace、容器或数据库。

本轮运行时只使用现有 `127.0.0.1:55438` 隔离 PostgreSQL、新建的一次性数据库、仅监听
`127.0.0.1:57788` 的测试 API，以及 `hermes:automated-tests:am-eval-r3` namespace。测试 API、
worker、源库、恢复库、dump、Vault 测试密钥和验证脚本均已停止或删除；生产容器只出现在只读容器
清单核对中，未连接其 API、数据库或 namespace。
